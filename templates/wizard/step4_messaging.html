Create a Telegram bot (optional):
1. Open Telegram, search @BotFather
2. Send /newbot — choose a name and username
3. Copy the bot token and paste it below

No Telegram? Leave it empty — you can chat from the browser instead via booa.app → Studio → Agent Console. Enable it after setup from the dashboard's Web Console card. You can also add Telegram later by re-running the wizard.
After setup, your agent starts automatically. With Telegram connected, message your bot and send /start. With the Web Console, enable it on the dashboard and connect from booa.app.

To set up a wallet later, tell your agent: "set up my wallet"
